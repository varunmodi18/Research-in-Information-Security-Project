# PARAMETERS

Frozen curve parameter sets (IA-07), generated by `tools/gen_params.py` and hardcoded into
`src/maka/params.py`. Curve: `E: y^2 = x^3 + x` over `F_p_field`, `p_field = 3 (mod 4)` so
`#E(F_p_field) = p_field + 1` (IA-02). Each set's generator `g` has prime order `r_group`.

| Set | p_field bits | r_group bits | cofactor | Notes |
|---|---|---|---|---|
| `toy` | 32 | 24 | 224 | Insecure by construction; hand-checkable traces at `-vvv` |
| `demo` | 256 | 251 | 20 | Default parameter set |
| `secure` | 512 | 501 | 1140 | |

All three verified (tests/test_curve.py) against:
- `g.is_on_curve()`
- `r_group * g == O`
- `cofactor * r_group == order == p_field + 1`

Domain naming (IA-02): this file and `params.py` use `p_field` and `r_group` only; a hygiene
test (`tests/test_hygiene.py::test_no_bare_p_binding_under_src`) forbids a bare `p` binding
anywhere under `src/`.
